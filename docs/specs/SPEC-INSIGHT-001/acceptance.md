# 수락 기준

## AC-001 (P0): 오늘 수유 요약

- Given: 오늘 `feeding` 기록이 여러 개 저장되어 있다.
- When: 오늘 요약을 계산한다.
- Then: 수유 횟수와 `ml` 총량이 반환된다.

## AC-002 (P0): 오늘 수면 요약

- Given: 오늘 `sleep_start`와 `sleep_end` 기록이 저장되어 있다.
- When: 오늘 요약을 계산한다.
- Then: 수면 횟수와 종료된 수면 총 시간이 반환된다.

## AC-003 (P0): 오늘 기저귀 요약

- Given: 오늘 기저귀 소변과 대변 기록이 저장되어 있다.
- When: 오늘 요약을 계산한다.
- Then: 소변/대변 횟수와 전체 기저귀 횟수가 반환된다.

## AC-004 (P0): 홈 요약 연결

- Given: 홈 화면이 로컬 저장소의 기록을 불러왔다.
- When: 홈 화면을 본다.
- Then: 오늘 요약 영역은 실제 기록 기반 수유, 수면, 기저귀, 마지막 상태를 표시한다.
