# 수락 기준

## AC-001 (P0): 같은 가족 원격 기록 조회

- Given: 사용자가 로그인했고 원격 family mapping이 있다.
- When: 기록 탭에서 날짜를 선택한다.
- Then: 앱은 같은 원격 `family_id`, `child_id`의 `baby_logs`를 조회해 타임라인에 표시한다.

## AC-002 (P0): 비구성원 접근 차단

- Given: 사용자가 해당 원격 가족 구성원이 아니다.
- When: 원격 `baby_logs`를 조회한다.
- Then: Supabase RLS에 의해 조회 결과가 없거나 실패하고, 앱은 로컬 기록만 표시한다.

## AC-003 (P0): 로컬 우선 중복 제거

- Given: 이 기기에서 만든 로컬 기록과 같은 내용의 원격 백업 row가 있다.
- When: 로컬 기록과 원격 기록을 병합한다.
- Then: 같은 기록은 한 번만 표시하고 로컬 기록을 우선한다.

## AC-004 (P1): 원격 실패 격리

- Given: 네트워크 오류나 원격 조회 오류가 발생한다.
- When: 기록 탭이 로드된다.
- Then: 로컬 기록은 계속 표시되고 원격 실패 안내만 표시한다.
