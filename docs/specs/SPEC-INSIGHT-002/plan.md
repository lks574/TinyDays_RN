## 구현 순서

1. `BabyLog` 배열과 기준 시각을 받아 최근 7일 집계와 평균을 반환하는 함수를 만든다.
2. 수면은 완료된 `sleep_start`/`sleep_end` 쌍만 총 시간에 반영한다.
3. 다음 행동은 최근 기록과 고정 기준으로 `feeding`, `sleep`, `diaper`, `none` 중 하나를 반환한다.
4. 인사이트 탭에서 `localBabyLogRepository`를 읽고 결과를 표시한다.
5. `npm run lint`, `npm run typecheck`, `npm test`로 검증한다.

## 테스트 계획

- 최근 7일 밖 기록 제외.
- 수유, 수면, 기저귀 총합과 7일 평균 계산.
- 완료되지 않은 수면 제외.
- 다음 행동 안내의 규칙 기반 결과 검증.
