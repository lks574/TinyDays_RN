# 수락 기준

## AC-001 (P0): 텍스트 입력 파싱

- Given: 홈 화면에 텍스트 기록 입력이 있다.
- When: 사용자가 `분유 120ml 먹었어`를 입력하고 파싱한다.
- Then: 앱은 `feeding` 후보를 확인 UI에 표시한다.

## AC-002 (P0): 저장 전 확인

- Given: parser 결과가 있다.
- When: 사용자가 아직 저장 버튼을 누르지 않았다.
- Then: 최근 타임라인에는 새 기록이 추가되지 않는다.

## AC-003 (P0): 수정 후 저장

- Given: 확인 UI가 표시되어 있다.
- When: 사용자가 타입, 수치, 메모를 수정하고 저장한다.
- Then: 수정된 값이 로컬 타임라인에 표시된다.

## AC-004 (P0): 낮은 confidence 확인

- Given: parser confidence가 낮은 결과가 있다.
- When: 결과가 반환된다.
- Then: 앱은 자동 저장하지 않고 확인 UI를 유지한다.
