# 수락 기준

## AC-001 (P0): 사진 탭 날짜별 목록

- Given: 현재 family context와 저장된 사진이 있다.
- When: 사용자가 사진 탭을 연다.
- Then: 선택된 아기의 사진만 날짜별로 표시된다.

## AC-002 (P0): 업로드 진입점

- Given: 사용자가 사진 탭에 있다.
- When: 업로드 버튼을 누르고 이미지를 선택한다.
- Then: 선택한 사진이 현재 가족, 선택된 아기, 현재 사용자, 날짜 기준 메타데이터와 함께 저장된다.

## AC-003 (P0): 권한 거부 처리

- Given: 사진 라이브러리 권한이 거부된다.
- When: 사용자가 업로드 버튼을 누른다.
- Then: 사진 선택과 저장을 중단하고 권한 안내 메시지를 표시한다.

## AC-004 (P1): 빈 상태

- Given: 선택된 아기에 저장된 사진이 없다.
- When: 사용자가 사진 탭을 연다.
- Then: 빈 상태와 업로드 진입점이 표시된다.
