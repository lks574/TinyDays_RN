# 수락 기준

## AC-001 (P0): 디자인 시스템 적용

- Given: 사용자가 가족 탭을 연다.
- When: 화면이 렌더링된다.
- Then: 헤더, 섹션, 입력, 버튼, 구성원 정보가 공통 디자인 시스템 컴포넌트와 `theme` 토큰 기반으로 표시된다.

## AC-002 (P0): 기존 저장 흐름 유지

- Given: 사용자가 가족 이름, 아기 이름, 생년월일을 입력한다.
- When: 저장 버튼을 누른다.
- Then: 기존 로컬 `family context`가 저장되고 화면 값이 저장 결과와 동기화된다.

## AC-003 (P0): 권한 표시 제한

- Given: 현재 구성원 정보가 있다.
- When: 가족 탭이 구성원 권한을 표시한다.
- Then: 역할은 `parent` 또는 `family` 기준으로만 표시된다.

## AC-004 (P1): 비공개 안내

- Given: 가족 탭이 표시된다.
- When: 사용자가 화면 하단 안내를 본다.
- Then: 가족과 아기 정보가 가족 단위 비공개 데이터라는 안내가 표시된다.
