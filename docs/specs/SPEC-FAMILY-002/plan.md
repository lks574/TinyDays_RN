# 구현 계획

## 태스크

- [x] T1: 기존 가족 탭 UI와 프로토타입 가족 화면 패턴을 비교한다.
- [x] T2: 가족 탭을 공통 디자인 시스템 컴포넌트와 `theme` 토큰 기반으로 정리한다.
- [x] T3: 등록된 아기와 현재 구성원/권한 표시를 프로토타입 리스트 형태로 조정한다.
- [x] T4: 저장 상태, 오류, 비공개 안내를 디자인 시스템 톤으로 정리한다.
- [x] T5: 검증 명령을 실행한다.

## 구현 순서

1. 기존 로컬 `family context` 로드/저장 흐름은 유지한다.
2. 헤더, 가족 정보 입력, 저장 버튼을 디자인 시스템 컴포넌트로 교체한다.
3. 등록된 아기 카드와 현재 구성원 행을 프로토타입의 프로필/역할 배지 패턴으로 조정한다.
4. 실제 초대/구성원 제거 기능은 열지 않고 MVP 로컬 모델의 현재 구성원만 표시한다.
