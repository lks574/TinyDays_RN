# 수락 기준

## AC-001 (P0): 홈 헤더와 오늘 요약

- Given: 홈 화면을 열었을 때
- When: 가족 context와 기록이 로드되면
- Then: 아기 이름, D+ 정보, 마지막 기록 상태, 오늘 요약이 디자인 시스템 토큰 기반 UI로 표시된다.

## AC-002 (P0): 빠른 기록 흐름 유지

- Given: 홈 화면의 빠른 기록 영역에서
- When: 사용자가 빠른 기록 버튼을 누르면
- Then: 기존 로컬 저장소에 기록이 저장되고 최근 타임라인이 갱신된다.

## AC-003 (P0): 텍스트 기록 확인 흐름 유지

- Given: 사용자가 텍스트 기록을 입력했을 때
- When: 내용 확인을 누르면
- Then: 파싱 결과 확인 UI가 표시되고, 사용자가 저장을 눌러야 기록된다.

## AC-004 (P1): 최근 타임라인 시각 구분

- Given: 최근 기록이 있을 때
- When: 홈 화면의 최근 타임라인을 보면
- Then: 기록 타입별 색상 점, 시간, 값, 메모가 읽기 쉬운 행 구조로 표시된다.
