# 수락 기준

## AC-001 (P0): 앱 시작 시 기록 복원

- Given: 로컬 저장소에 `BabyLog` 목록이 저장되어 있다.
- When: 홈 화면이 열린다.
- Then: 앱은 저장된 기록을 불러와 최근 타임라인에 표시한다.

## AC-002 (P0): 빠른 기록 영구 저장

- Given: 사용자가 홈 화면에 있다.
- When: 사용자가 빠른 기록 버튼을 누른다.
- Then: 앱은 새 `BabyLog`를 로컬 저장소와 화면 상태에 모두 반영한다.

## AC-003 (P0): 텍스트 확인 후 영구 저장

- Given: 사용자가 텍스트 기록을 입력하고 파싱 결과를 확인했다.
- When: 사용자가 저장 버튼을 누른다.
- Then: 앱은 확인된 `BabyLog`를 로컬 저장소와 화면 상태에 모두 반영한다.

## AC-004 (P1): 저장소 실패 처리

- Given: 로컬 저장소 읽기 또는 쓰기가 실패한다.
- When: 홈 화면이 저장소 작업을 수행한다.
- Then: 앱은 중단되지 않고 사용자에게 저장소 오류 상태를 표시한다.
