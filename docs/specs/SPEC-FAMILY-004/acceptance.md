# 수락 기준

## AC-001 (P0): Parent 초대 생성

- Given: 사용자가 로그인했고 원격 가족 mapping이 있으며 역할이 `parent`다.
- When: 사용자가 가족 초대 생성을 요청한다.
- Then: 앱은 Supabase RPC를 통해 초대 코드를 받고 화면에 표시한다.

## AC-002 (P0): 초대 코드 수락

- Given: 다른 로그인 사용자가 유효한 초대 코드를 가지고 있다.
- When: 사용자가 초대 코드를 입력해 수락한다.
- Then: 서버는 해당 사용자를 `family_members`에 `family` 역할로 추가하고 앱은 remote mapping을 저장한다.

## AC-003 (P0): 초대 생성 권한 제한

- Given: 사용자가 `family` 역할이거나 가족 구성원이 아니다.
- When: 사용자가 초대 생성을 요청한다.
- Then: 서버는 요청을 거부하고 초대 코드를 만들지 않는다.

## AC-004 (P0): 잘못된 초대 코드 거부

- Given: 초대 코드가 없거나 만료되었거나 취소되었다.
- When: 사용자가 초대 코드를 수락한다.
- Then: 서버는 가족 구성원 추가를 거부한다.

## AC-005 (P1): 로컬 흐름 유지

- Given: Supabase 설정 또는 session이 없다.
- When: 사용자가 가족 탭을 연다.
- Then: 앱은 기존 로컬 가족 정보와 기록/사진 저장 흐름을 계속 사용할 수 있다.
