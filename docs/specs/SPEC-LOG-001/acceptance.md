# 수락 기준

## AC-001 (P0): 빠른 기록 버튼 표시

- Given: 사용자가 홈 화면에 진입했다.
- When: 화면이 렌더링된다.
- Then: 수유, 수면, 기저귀, 체온, 목욕, 메모 진입점이 표시된다.

## AC-002 (P0): 버튼 탭으로 기록 후보 생성

- Given: 홈 화면에 빠른 기록 버튼이 있다.
- When: 사용자가 버튼을 탭한다.
- Then: 앱은 `quick_button` source의 임시 `BabyLog`를 생성한다.

## AC-003 (P0): 최근 타임라인 표시

- Given: 빠른 기록으로 생성된 기록이 있다.
- When: 홈 화면을 확인한다.
- Then: 최근 타임라인에 생성된 기록이 최신순으로 표시된다.

## AC-004 (P0): 저장소 제외

- Given: PR-05 범위다.
- When: 기록이 생성된다.
- Then: 서버 저장이나 영구 저장소 저장 없이 화면 로컬 상태에만 반영된다.
