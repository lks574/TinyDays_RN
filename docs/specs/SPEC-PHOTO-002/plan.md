## 구현 순서

1. 기존 사진 업로드와 로컬 저장 흐름은 유지한다.
2. 헤더, 업로드 버튼, 상태 메시지, 빈 상태를 디자인 시스템 컴포넌트로 교체한다.
3. 기간 필터와 privacy badge를 추가한다.
4. 날짜별 사진 그리드를 프로토타입의 촘촘한 3열 형태로 조정한다.
