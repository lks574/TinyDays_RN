# 수락 기준

## AC-001 (P0): 디자인 시스템 적용

- Given: 사용자가 사진 탭을 연다.
- When: 화면이 렌더링된다.
- Then: 헤더, 버튼, 필터, 빈 상태가 공통 디자인 시스템 컴포넌트와 `theme` 토큰 기반으로 표시된다.

## AC-002 (P0): 사진 그리드 표시

- Given: 선택된 아기에 저장된 사진이 있다.
- When: 사용자가 사진 탭을 연다.
- Then: 사진이 날짜별 그룹과 3열 그리드로 표시된다.

## AC-003 (P1): 기간 필터

- Given: 여러 날짜의 사진이 있다.
- When: 사용자가 오늘, 최근 7일, 이번 달 필터를 선택한다.
- Then: 선택한 기간에 해당하는 날짜 그룹만 표시된다.

## AC-004 (P0): 비공개 범위 안내

- Given: 사진 탭이 표시된다.
- When: 사용자가 화면 상단을 본다.
- Then: 가족만 볼 수 있는 사진이라는 안내가 표시된다.
