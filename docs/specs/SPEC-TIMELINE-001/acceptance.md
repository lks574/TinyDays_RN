# 수락 기준

## AC-001 (P0): 오늘과 이전 날짜 구분

- Given: 오늘 기록과 어제 기록이 저장되어 있다.
- When: 사용자가 기록 탭에서 오늘 날짜를 선택한다.
- Then: 오늘 기록만 표시된다.

## AC-002 (P0): 같은 데이터 소스 사용

- Given: 홈 화면의 빠른 기록 또는 텍스트 기록으로 `BabyLog`가 저장되어 있다.
- When: 사용자가 기록 탭을 연다.
- Then: 기록 탭은 `localBabyLogRepository`에서 같은 기록을 불러와 표시한다.

## AC-003 (P0): 시간순 목록

- Given: 선택 날짜에 여러 기록이 저장되어 있다.
- When: 사용자가 해당 날짜를 조회한다.
- Then: 기록은 이른 시간부터 늦은 시간 순서로 표시된다.

## AC-004 (P1): 기록 타입 필터

- Given: 선택 날짜에 여러 타입의 기록이 저장되어 있다.
- When: 사용자가 특정 기록 타입 필터를 선택한다.
- Then: 해당 타입의 기록만 표시된다.

## AC-005 (P1): 빈 상태

- Given: 선택 날짜에 기록이 없다.
- When: 사용자가 해당 날짜를 조회한다.
- Then: 기록이 없다는 상태가 표시된다.
